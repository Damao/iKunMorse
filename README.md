# iKunMorse

M5StickC Plus 上的听音摩斯训练器。项目以 Koch 顺序从 `E`、`T` 开始，先听声音，再用设备按键选择答案。

## 当前玩法

- 新字母会先进入教学页：屏幕显示大字母、点划，并播放一次完整摩斯声音。
- `A / →` 开始教学或选择右侧答案；`B / ↑` 重播教学或选择左侧答案。
- 答题页默认隐藏点划，长按 `A` 才显示提示并重播。
- 当前关使用掌握格：当前新字母答对 `+1`，答错 `-1`，填满 `6/6` 才解锁下一字母。
- 老字母会穿插复习；答错的字母会提高复习权重，短期内更常出现。
- 长按 `B / ↑` 进入自由输入模式；再长按一次返回游戏。

## 自由输入

自由输入不计分，适合随手拼单词：

- `A / →` 短按是点，长按是划；按下时声音持续，松开时停止。
- 停顿约 0.7 秒后，当前点划会自动译成大字母并追加到输入串。
- `B / ↑` 短按删除当前点划；没有未提交点划时删除最后一个字母。
- 切换模式时会清空自由输入内容。

## 存档

训练进度保存在 ESP32 的 NVS 中：

- 已解锁字母数量
- 当前关掌握格进度

重启或重新上电后，会复习当前最新字母并继续原来的关卡。错题复习权重属于短期状态，重启后会重新计算。

## 编译与烧录

在 Arduino IDE 中选择：

- Board: `M5StickC Plus`
- Port: 对应的 `/dev/cu.usbserial-*`

M5StickC Plus 的 FTDI 串口不使用 `921600`。本项目统一使用官方支持的 `750000` 波特率；烧录时请先断开网页监视器的串口连接。

## Mac 屏幕镜像

仓库中的 `iKunM5Mirror.h` 是 iKun M5 Monitor 的固件适配器。当前固件已经接入：

```cpp
#include "iKunM5Mirror.h"
```

网页监视器位于：

`/Users/bigcat/Code/iKunM5Monitor`

启动本地网页后，在 Chrome 中打开监视器并连接 M5。正常连接时网页会收到 `IKUNREADY`，随后显示 `IKMF` 屏幕帧。网页内置串口诊断面板，可查看收到字节数、帧大小和原始数据。

镜像协议特点：

- 750000 baud
- 默认最多 4 FPS
- RGB565 横向 RLE 压缩
- 静态画面去重
- 超过 payload 上限时直接丢帧，不让串口队列堆积
